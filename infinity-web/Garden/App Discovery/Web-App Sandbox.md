**Target URL & Setup Parameters**

- **Address to enter:** `[https://web.whatsapp.com](https://web.whatsapp.com)`
- **Required Setting:** Enable **Desktop Mode** (or change User-Agent to Desktop) inside the container settings so WhatsApp Web doesn't redirect you to the mobile landing page.
