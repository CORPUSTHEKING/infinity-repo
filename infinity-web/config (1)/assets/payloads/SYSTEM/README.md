# 🛠️ System Tools (/assets/payloads/SYSTEM/)
Standalone JSON logic skeletons for low-level operations.

## Components
* **cssInjector.json**: Fetches and injects raw CSS into the <head>, removing hardcoded <link> tags.
* **iterator.json**: The directory walker. Fetches `list.json` and recursively processes data payloads.
* **listener.json**: Interaction binder. Scans for `data-target-drawer` to handle UI state dynamically.
